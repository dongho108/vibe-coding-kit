# 실결제 전환 체크리스트

테스트 결제로 돌던 서비스에서 실제로 돈을 받기까지의 순서입니다.
Claude Code에서 `/live` 라고 치면 이 순서대로 같이 진행합니다.

모든 내용은 토스페이먼츠 공식 문서 기준이고(2026년 9월 확인), 정책은 바뀔 수 있습니다.
각 단계의 링크에서 최신 내용을 확인하세요.

## 1. 사업자등록과 통신판매업 신고

- [ ] 사업자등록번호가 있다
  - 전자결제 신청 첫 화면이 사업자등록번호 입력입니다.
  - 토스 FAQ: 비사업자는 "7일 이내에 배송되는 유형의 기성제품에 한하여" 입점 가능. 서비스·콘텐츠·구독·예약은 사업자등록이 필요합니다.
  - [토스 사업자등록·통신판매업 무료 신청](https://onboarding.tosspayments.com/business-registration/intro) (단독대표 개인사업자만)
- [ ] 통신판매업 신고번호가 있다 (또는 면제 대상인지 확인)
  - [통신판매업이란](https://docs.tosspayments.com/resources/glossary/online-business)
  - 신고번호가 없으면 국민카드 심사가 제외됩니다.

## 2. 심사용 사이트 준비

[카드사 심사 안내](https://www.tosspayments.com/blog/articles/semo-7) 기준입니다.

- [ ] 바닥글에 상호명, 대표자명, 사업자등록번호, 사업장 주소, 전화번호, 통신판매업 신고번호
- [ ] 상품 금액과 결제 금액이 같다
- [ ] 바로 살 수 있는 상품이 1개 이상, 상품 사진이 제대로 보인다 (임시 사진·임시 상품 교체)
- [ ] 콘텐츠·서비스 상품은 제공기간과 환불정책이 보인다
- [ ] 회원만 살 수 있다면 심사용 테스트 계정을 준비했다
- [ ] 배포된 사이트에서 결제 연동이 끝까지 된다

## 3. 전자결제 신청

- [ ] [이용 신청](https://onboarding.tosspayments.com/registration/business-registration-number?from=inbound)
- [ ] 신분증(주민번호 뒷자리까지 보이는 것), 통장사본 등 서류 제출. 사업자 유형마다 다릅니다.
- [ ] 구독 서비스면 자동결제(빌링)도 신청 ([자동결제는 리스크 검토와 추가 계약 필요](https://docs.tosspayments.com/guides/v2/billing))
- [ ] 비용 확인: [요금 안내](https://www.tosspayments.com/about/fee)
- 심사: 입점 계약 심사 → 카드사 심사 (평균 영업일 7일)

## 4. 내 테스트 키로 교체하고 웹훅 등록

- [ ] [개발자센터 API 키](https://developers.tosspayments.com/my/api-keys)에서 내 상점의 테스트 키로 교체
  (단건·예약 `test_gck_`/`test_gsk_`, 구독 `test_ck_`/`test_sk_`)
- [ ] [웹훅 등록](https://docs.tosspayments.com/guides/v2/webhook): 상점아이디(MID)별로 따로 등록
- [ ] 테스트 결제·실패·금액 조작·중복 승인·취소를 처음부터 다시 확인

## 5. 라이브 키로 교체 (카드사 심사 통과 후)

- [ ] `live_` 키를 **Vercel Production 환경에만** 넣었다. 내 컴퓨터(`.env.local`)와 미리보기는 테스트 키 그대로
- [ ] 라이브 MID에 웹훅이 등록되어 있다
- [ ] 재배포했다

## 6. 토스 배포 체크리스트

[배포 체크리스트](https://docs.tosspayments.com/guides/v2/deploy-checklist) 기준입니다.

- [ ] 라이브 키, 선택된 상점아이디(MID)가 맞다
- [ ] 시크릿 키가 코드·GitHub에 노출되지 않았다
- [ ] 제공할 카드사 심사를 통과했다
- [ ] 결제 흐름 전체, 취소·부분 취소, 에러 처리가 된다
- [ ] 여러 브라우저와 모바일에서 된다

## 7. 첫 실결제 확인 (키트 권장)

- [ ] 가장 싼 상품을 본인 카드로 결제하고 전액 취소했다
- 카드 결제는 매입 전에 취소하면 바로 환불되고, 결제 수수료도 함께 환급됩니다. ([결제 취소](https://docs.tosspayments.com/guides/v2/cancel-payment))

## 알아둘 것

- 정산 주기는 계약마다 다릅니다. 계약서의 주기를 확인하세요. ([정산](https://docs.tosspayments.com/resources/glossary/settlement))
- 처음에는 월 정산한도가 기본값입니다. 초과분은 다음 달 첫 영업일에 지급됩니다.
